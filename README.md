# 岛津中国全域增长 BI 看板 Demo

根据《BI数据看板需求》制作的交互原型，覆盖官网、公众号、视频号、小程序、抖音、小红书、知乎、B站、微博，以及会员、表单、培训三类内部业务数据。使用 documents 能力读取需求，参考 product-designer 的信息架构与视觉层级方法完成设计。

## 打开方式

双击 `岛津中国BI看板Demo.html`，使用 Chrome、Edge 或 Safari 打开。页面为单文件，包含样式、脚本和模拟数据，不需要安装依赖、登录或连接网络。在线版本使用相同页面。

## 可以体验的内容

- **经营总览**：核心指标、同期趋势、平台贡献、行业结构、转化漏斗、目标进度与动态业务洞察。
- **媒体矩阵**：渠道趋势、发布/触达热力图、平台排序、渠道明细与高表现内容样本。
- **受众分析**：模拟性别与年龄结构、区域贡献、行业与区域联动筛选。
- **转化分析**：注册、有效表单、商机链路，培训报名与到课并行分支，以及渠道成本与转化效率。
- **数据源管理**：接入目录、自定义数据源、可用字段配置、CSV 字段映射、校验、覆盖导入和样本恢复。
- **角色与权限**：管理层、华东区域经理、媒体运营、数据分析师、数据管理员的访问范围、字段可见性及导出策略。

全局筛选包括年度、周期、平台、业务行业与区域。点击平台排序行、表格“查看”或热力图，可打开明细。趋势图支持图例隐藏系列、悬停明细和点击月份查看数值。

## 导入演示

1. 顶部角色切换为“数据管理员”，进入“数据源管理”。
2. 点击“导入 CSV”，选择随附的 `外部数据导入示例.csv`。
3. 确认映射，选择“覆盖相同维度记录”，点击“校验与预览”。
4. 校验通过后点击“确认导入”，看板即使用新记录。
5. 进入媒体矩阵，筛选 2026 年、9 月、小红书、医药生物、华东，可核对浏览/播放量为 158,000。

导入键为 **月份＋平台＋行业＋区域**。覆盖按整行快照替换，未映射的可选指标保留为未知。文件内重复键、负数、非整数计数、无效维度和转化大小关系错误会被拒绝。月份支持 2025-01 至 2026-12；最大文件 2 MB、10,000 行。

数据目录中的行业为教育科研、医药生物、临床医疗、食品安全、工业制造、公安司法、环境化工、其他；区域为华东、华南、华北、中西部。新增平台需先创建数据源。CSV 导入与配置均只保存在当前页面内存中，刷新页面后恢复初始样本。

## 数据口径与边界

- 所有业务数据均为模拟数据，默认分析 2026 年 1–9 月；全年选项包含模拟未来月份。完整样本包含 24 个月、9 平台、8 行业、4 区域，共 6,912 条月度维度记录。
- 浏览/播放量为次数，不代表独立触达人数。跨平台 UV 不去重加总；仅官网与小程序提供 UV/PV，在渠道明细中按月展示。
- 粉丝总量采用选定周期末快照，净增关注为新增关注减取消关注。行业与区域归属为模拟拆分，跨平台粉丝未去重。
- 未提供的指标显示“—”。汇总存在缺失值时仅累计已知记录；正式版本应显示字段覆盖率，并对不完整指标限制同比与决策分析。
- 有效商机 ≤ 有效表单 ≤ 新注册；培训报名 ≤ 有效表单，培训到课 ≤ 培训报名。商机与培训是并行分支。
- 年龄、性别、内容排名与营销成本为扩展模拟维度。画像由互动权重推演，内容样本不等同于全量内容明细。
- 2026 目标基于 2025 同周期 × 1.25；2025 目标基于本期基准 × 1.18，均为演示计划。
- API 连接器是配置原型，没有连接真实平台接口。CSV 是实际可操作的本地导入流程，页面不上传文件。
- 权限是前端交互演示，导出应用当前角色的行范围与字段限制。正式上线必须在后端实现身份认证、行级/字段级权限与审计，不能依赖前端隐藏。

## 已完成验证

桌面首屏与六个模块切换、平台筛选、渠道明细和指标弹窗、媒体运营的转化访问限制、华东区域经理的固定区域与 648 条导出范围、CSV 负数拦截与 3 条合法覆盖导入，均已实际验证。390px 与 320px 窄屏无页面横向溢出；宽表格在组件内横向滚动。

## 后续正式接入建议

先确认每个平台可获取字段与更新频率，统一平台/月份/行业/区域编码。浏览、播放、曝光需保存各自原始口径；会员与表单按匿名用户标识去重，并明确首触或末触归因。采用原始数据层、标准月度汇总层与看板指标层，建立导入版本、质量告警与更新审计，再对接统一身份与权限服务。
